\# 🎨 Collaborative Canvas (Vanilla JS + Node + Socket.io)



A real-time, multi-user drawing app built with \*\*Vanilla JavaScript\*\* and \*\*HTML5 Canvas\*\* on the frontend, and \*\*Node.js + Socket.io\*\* on the backend.  

Multiple users can draw simultaneously and see each other’s strokes live.
